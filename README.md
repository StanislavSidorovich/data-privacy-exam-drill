# Data Privacy Exam Drill

Practice questions for the **Data Privacy, Security and Ethics** course (NOVA IMS, 2026/2027).

**Open it:** https://stanislavsidorovich.github.io/data-privacy-exam-drill/

## What's inside

- **302 questions** (multiple choice and true/false) covering all 7 chapters, each with a short explanation and a chapter reference.
- **Mock exam**: 25 random questions spread across chapters, 40-minute timer, free navigation, and the official scoring: +0.8 per correct answer, −0.8/n per wrong answer (n = number of options), 0 for a blank. You get a full review with explanations at the end.
- **Chapter tests**: run every question of one chapter, with instant feedback.
- **Practice**: mix any chapters you choose.
- **My mistakes**: questions you answered wrong come back until you get them right.
- **Question bank**: search and browse all questions with answers.
- Light/dark theme and four text sizes. Works on phone, tablet and laptop.

Direct links: `#exam`, `#bank`, `#ch1` … `#ch7` (for example `…/data-privacy-exam-drill/#ch5`).

## Notes

- This is an unofficial study aid written from the course slides. It is **not** the real exam, and the real questions are unknown.
- The course slides are not included in this repository.
- Your progress is stored only in your own browser.
- Found a wrong answer or unclear question? Open an issue.

To run it locally, download the repo and open `index.html` in a browser (keep `questions.js` next to it).
